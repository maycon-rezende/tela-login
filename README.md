# Tela de Login

Projeto avaliativo de Git e GitHub. Página de login com tema escuro e validação de campos via JavaScript, além de dashboard e cadastro de usuário.

## Funcionalidades

- Login com validação de campos obrigatórios (`index.html`, `style.css`, `script.js`)
- Painel principal após login (`dashboard.html`)
- Cadastro de novos usuários (`cadastro.html`)

## Como executar

Basta abrir o arquivo `index.html` em um navegador. Não há dependências externas.

## Histórico de versões

- **v1.1.0** — Adiciona dashboard, cadastro de usuário e corrige erro estrutural na página de login.
- **v1.0.0** — Estrutura inicial do projeto com login e validação de campos.
